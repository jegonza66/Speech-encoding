# 0. Create a log file in the current directory:
./script_output.log

# 1. Enter wsl

# 2. Create a screen session ('session' will be the name, it may be usefull to use something informative):
>>screen -S session

# 3. Run the .py file:
>>./.venv/Scripts/python.exe -u 'name_of_the_file'.py < /dev/null >  ./script_output.log 2>&1 &

# 4. Check the process is running:
>>ps aux | grep 'name_of_the_file'.py
The first column indicates the tag (###) of the process, to kill it run:
>>kill ###

# 4. See the log (last 300 lines):
tail -n 300 ./script_output.log

# 5. Exit the screen session:
ctrl+a, then d

# 6. Kill the terminal

# 7. Open WSL and run the following code to reatach to the process:
>>screen -r session

# 8. Verify the state of the code. ALWAYS detach from the session before killing the terminal.

# 9. To end the session from inside, simply run:
>> exit
From outside:
>>screen -X -S session quit

# To list all current sessions from WSL:
>> screen -ls
